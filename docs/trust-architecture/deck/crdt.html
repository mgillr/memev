CRDT-Merge is our convergence engine. Plain version: when many independent parties each add to shared work, in any order and without a central server deciding, everyone is meant to end with the same record. The result comes from fixed mathematical rules, not from a central authority and not from a language model's opinion. That is what is intended to make connected intelligence possible across sites, countries and organisations that will never hand their data to one owner.
