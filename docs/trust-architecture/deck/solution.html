Memev · Trust architecture for AI

Memev is not another model, memory vendor or agent framework. It sits between the AI an organisation already uses and the people, projects and systems that do the work. It supplies four things: shared context, coordination, authority and policy, and evidence. Because it is application agnostic, the organisation can change AI providers without losing its connected intelligence.
