# A new hire's first session

> **Example. Planned.** This walk-through shows the intended shape of shared memory for a company on Business. Steps marked *today* work now; steps marked *planned* do not exist yet. Names are roles, and the data is fictional. Back to [custom module use cases](../use-cases.md).

**Related use case:** [onboarding a new hire](../use-cases.md#8-onboarding-a-new-hire).

## Steps

1. *Planned.* A new member joins with an invite trusted for the company and work areas, and not for any
   client area.
2. *Planned.* Their first session returns the company's north star, the active projects and the last
   quarter's decisions.
3. *Planned.* They ask about a client engagement they are not on. The answer is "nothing in the vault".
   Their computer never received that area, and their keys could not open it.

## Acceptance checks

1. The first session returns the north star, active projects and recent decisions.
2. A question about a client area the person is not on returns nothing, and does not hint that a note exists.
3. A fact the new person adds is returned to the next new hire.
