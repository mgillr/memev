### Fixed

- Every test file and helper that starts a memev daemon now stops it in an after or t.after hook that also runs on failure, so a failing or filtered run leaves no server behind.
- The port test no longer starts a daemon in a file-level before hook; the daemon is started lazily by the tests that need it, so a filtered run does not leak a daemon.
- The doctor-vaults test now checks that the 99 ports above its vault are all free before holding them, and re-rolls the sandbox port up to 20 times until it finds a clear range.
