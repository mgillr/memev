### Added

- `memev verify` now runs scope criteria. It lists what changed since the contract's recorded base (the commits reachable from HEAD and not from the base, tracked changes, untracked files and files hidden by skip-worktree or assume-unchanged) and fails naming every path outside the task's globs, with the commit or "uncommitted". A commit with one `Contract-Task: <contract id> <task id>` trailer is judged against that task's scope, a commit with none against the union of the task scopes, a commit naming more than one task or another contract's task fails, and a merge is judged on what it adds beyond its parents. Ignore rules come only from the `.gitignore` files tracked at the base. Scope has the same gates and vault confinement as command criteria, git runs with fsmonitor, hooks, filter and merge drivers switched off, and git failing or a missing base makes the criterion BLOCKED. `changelog.d/<SR id>.md` and a `docs/MODULES.md` that the generator taken from the base reproduces count as in scope.
