### Added

- The red-team gate (`scripts/gate/redteam-gate.mjs`, engine code in `src/engine/redteam-gate.mjs`): a contract is signed only with a red-team record that is complete, bound to the spec's hash and to a reviewed commit, signed by a trusted reviewer key, and closed by a clean round or a signed stop decision. It reports every failing rule, not only the first. `docs/CONTRACTS.md` explains the record and the rules.
- The engine runs the red-team gate itself: `memev contract new`, `memev_contract_draft`, `memev_contract_from_request` and `memev_contract_amend` refuse a spec that is not SIGNABLE, a draft that no spec backs and a draft whose tasks differ from its spec, and `memev contract sign` and `memev_contract_sign` judge the draft again. This applies wherever the repository holds red-team records or `contracts.redteam_required` is on, for local and tunnel callers alike. `memev verify` stays BLOCKED for a spec whose record ends with a stop decision until a clean implementation round covers the current in-scope files. The suite and the pull request check run the gate's report over the repository.
