### Added

- `memev connect` takes several apps in one call, for example `memev connect claude-code cursor vscode`, and connects exactly those. Every name is checked before any file changes, so an unknown name connects nothing. `memev connect` and `memev connect all` still connect every app found, and still skip the apps you disconnected. The remote setup screen can send the apps the person ticked in one command.
- Memev connects more AI apps, each at the path and key its own MCP docs give: Qwen Code, Kimi Code CLI, Factory Droid, Augment (Auggie CLI), Tabnine CLI, iFlow CLI, Warp, Mistral Vibe, LM Studio, AnythingLLM, oterm, Muse Code, ZCode, MCPHub for Neovim, CodeBuddy Code, Qoder CLI, OpenHands CLI, Cline, Kiro, Junie, Amp, Kilo Code and Amazon Q Developer CLI. They get the MCP server and the protocol through the MCP instructions. Where an app's docs name no Windows location (Factory Droid, Augment, Tabnine CLI, Warp, Muse Code, ZCode, MCPHub, CodeBuddy Code, Qoder CLI, OpenHands CLI, Cline, Kiro, Junie, Amazon Q Developer CLI), Memev connects it on macOS and Linux only, and on Windows lists it as found, not supported yet.
- More apps are found and listed as found, not supported yet, each with the way to add Memev by hand: Jan, Cherry Studio, BoltAI, Lingma, Rovo Dev CLI and Crush, beside Roo, Continue, JetBrains AI and Goose. docs/CLIENTS.md gives the reason for each, and lists the apps Memev cannot find because their docs name no file or folder.
