### Added

- With consent, Memev adds the Memev memory tools (recall, remember, checkpoint, status, why) to the connected app's permissions.allow, so the app runs them without a prompt each time; the write and contract tools still prompt. Consent is a question at memev init (on a terminal) or the --allow-tools flag on memev connect; memev disconnect removes the entries again. It is off unless you opt in, and it never touches your other permissions.

### Fixed

- A yes stored at init now survives a disconnect: the next memev connect puts the entries back, and the checklist reads them from settings.json, so it never says the tools are allowed when they are gone.
- The consent can be taken back: memev connect claude-code --no-allow-tools (or --allow-tools=false) removes the entries and stores the no, so a later plain connect does not add them back.
