### Added

- With consent, Memev adds mcp__memev to Claude Code's permissions.allow (~/.claude/settings.json), so Claude Code runs Memev's tools without a prompt each time. Consent is a question at memev init (on a terminal) or the --allow-tools flag on memev connect claude-code; memev disconnect claude-code removes the entry again. It is off unless you opt in, and it never touches your other permissions.
