### Added

- `memev connect cursor --project <dir>` writes an always-on rule to `<dir>/.cursor/rules/memev.mdc` (`alwaysApply: true`), so the memory rule is in every session of that project, not only at session start. `memev disconnect cursor` removes it. The Cursor stop hook now continues the session with a `followup_message` (bounded by `loop_limit`) when an operator task is waiting on this seat, and CLIENTS.md documents Cursor's hook limits.
