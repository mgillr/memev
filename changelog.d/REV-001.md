### Security

- The invite backup address is validated before it is handed to git fetch, refusing option-shaped values, remote-helper values, and non-remote strings, while accepting every remote form a vault origin can hold, including file:// URLs and plain absolute paths.
- The fetch passes --end-of-options before the remote so git never reads the backup value as an option; on git older than 2.24 the refresh fails with a note that says to upgrade git or drop the backup.
