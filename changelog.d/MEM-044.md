### Added

- `memev connect` now detects OpenCode (`~/.config/opencode`) and GitHub Copilot CLI (`~/.copilot`), registers the memev MCP server in each config. For OpenCode, the instructions block is added to `AGENTS.md` unless `~/.claude/CLAUDE.md` already exists and `AGENTS.md` is missing (to avoid switching off Claude rules). For Copilot CLI, the server entry goes in `mcp-config.json` (honouring `COPILOT_HOME`). Disconnect restores the files as before.
