### Added

- `memev connect` now detects OpenCode (`~/.config/opencode`) and GitHub Copilot CLI (`~/.copilot`), registers the memev MCP server in each config. For OpenCode, the instructions block is skipped when the other client's rules file is already present and the OpenCode one is missing, so existing rules stay active. For Copilot CLI, the server entry goes in `mcp-config.json` and the instructions block in `copilot-instructions.md`, both honouring `COPILOT_HOME`. Disconnect restores the files as before.
