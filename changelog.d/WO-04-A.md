### Added

- `scripts/metrics/report.mjs` renders the weekly funnel report: package downloads, release-host downloads, paid licence activations and, optionally, the opt-in milestone rows, each as the count per day, per week and the total, from count files handed to it as flags. An activation row marked as a trial, with `"trial": true` or with `1` as a SQL export gives it, is never counted as paid: the trials print on a line of their own, and so do any refused activations. A row with no trial field counts as paid, as the product reads a licence with none, and the page prints how many issued rows had none. A row whose date is not a real calendar date counts in the total only. It is a development tool that reports nothing anywhere and is not in the npm package file list.
- `scripts/metrics/gates.json` holds the month-6 gates (installs at or above 5,000 by month 6; free-to-paid, the paid activations over installs, at or above 1 percent once sync has shipped) and says which counted number stands for installs: package downloads, release downloads or both, never activations. The file names both, package and release-host downloads together, and the installs gate prints them as downloads, because a download is not an install. The page header renders each gate with its measured value, threshold and pass or miss, and editing the file changes the header with no change to the program.
