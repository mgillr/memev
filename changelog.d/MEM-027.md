### Fixed

- A moved address produces 'vault address changed: run memev join --refresh', and join --refresh fixes it.
- `memev join --refresh` fetches the signed address record from the vault's git backup (the remote the invite records) into a cache, and takes it only when the vault's key signed it. When this computer has no record to follow, the hook and the command say to get a new invite (`memev invite` on the vault's computer, then `memev join <code>`) instead of suggesting `--refresh`.
- A first `memev join` to an address that does not answer says "no answer at <address>" and gives no advice about a moved vault.
