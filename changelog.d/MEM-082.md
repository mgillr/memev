### Added

- `memev update <tarball>` installs the newest version from a local tarball into a new runtime folder and points the launcher at it. The version check is opt-in and off by default: when it is on, `memev doctor` and `memev status` read a static version file whose location comes from the vault config and show one update available line when it names a newer version. It reads only that local file and makes no network call.
