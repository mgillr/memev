### Fixed

- The device-proof gate is decided from the device kind as stored before the client is reclassified, so a keyless computer token cannot pass it by claiming to be a cloud client.
- A remote grep criterion caps the pattern length and terminates the match when it does not finish in time, so a pathological pattern cannot hang a verify.
- The grep time of one verify with remote patterns is capped as a whole, so many pathological criteria cannot stall the vault for one second each; the criteria past the cap fail unchecked.
