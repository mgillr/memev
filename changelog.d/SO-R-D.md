### Added

- `docs/INSTALL-FOR-AI.md` is a step-by-step runbook for an AI app that installs Memev at the person's request. It has nine sections (operating system and runtime, installation path, permission, the pinned release, version and health, the smoke test, connecting approved clients, reporting results, and failure handling), every command on the page is in `memev help` or the README install section, and it names no client product and no version. Init runs with `--no-connect`, so init itself connects no AI app; Memev still connects the apps it detects a few seconds after it starts, so the page has the person approve each connected app and run `memev disconnect <client>` for each one they do not want. The page gives `memev ready --json` a timeout, warns against pasting a connector URL or a token into a shared chat, and names the undo commands.
- `memev ready --json` prints one machine-readable object: `ok`, `smoke`, and one entry per connected client with `id`, `name`, `joined`, and `joinedAt`, the time of its first heartbeat or null. Exit codes are 0 when ready, 1 when it is not ready within the timeout, and 2 for a usage error.
- The runbook test checks the page against the real CLI: the section order; the command coverage, where each command the page runs must be a README install command exactly or a form `memev help` lists with its flags, and invented commands and flags are checked to be refused; the machine-readable forms and their fields; the `ready --json` exit codes and smoke semantics; `--no-connect` on every init the page runs; and the ban on client product names and versions.
