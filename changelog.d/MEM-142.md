### Added

- `memev setup remote --code <code>`: a customer-initiated, outbound,
  time-limited, mutually authenticated remote setup session. The operator
  can run a fixed allowlist of Memev commands on the customer's install.
  The session is logged on the customer's computer, can be revoked at any
  moment, and ends by itself.

### Fixed

- A first command arriving in the same read as the handshake frame no
  longer hangs the session; the channel keeps pumping after the handshake
  resolves.
- `memev setup remote stop` no longer signals a process whose `.status`
  file is stale; it only signals a live memev setup process and clears
  stale files.
- `connect` now requires the app to be found and supported on the
  customer's install, not just present in the allowlist.
- `setup.session_max_minutes` above 240 now caps at 240 instead of
  falling back to 60.
- A non-list command frame is refused with a clear message instead of
  crashing the session.
- The customer now sees why the session ended when a frame is refused.
