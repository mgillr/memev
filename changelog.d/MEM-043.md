### Changed

- When Memev cannot edit an app's config (a file that does not parse, or that is not a JSON object), the checklist names the file and says why, instead of only "memev connect <app>". `memev connect <app> --print` prints exactly what Memev would add to each of that app's files, to paste by hand, and changes nothing. Once it is pasted, `memev connect <app>` finds itself already there.
