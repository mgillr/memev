### Added

- `compose.trial.yaml` starts the on-prem trial with one command: build from the repository Dockerfile (or set `MEMEV_IMAGE` to a prebuilt name), keep the vault in the `memev-vault` named volume, publish the port on `127.0.0.1:7787` only, restart unless stopped, and declare a health check. The image carries `org.opencontainers.image` labels for title, description, licenses and version. The container entry point runs the container doctor checks at start and logs one line per failed or warned check. `docs/DOCKER.md` documents the three-step trial path. Publishing the image to a registry needs the owner go; build it locally with `docker compose -f compose.trial.yaml build`.
