### Added

- `memev cloud connect <app>` waits until the app actually uses the connector, so a stale cloud seat from an earlier run no longer counts as a connection, and a missing or non-numeric `--timeout` falls back to 120 seconds instead of waiting forever. The plan line prints the number of connectors the tier covers and says not capped only when the tier has no number, and the person-facing lines use the app display names.
