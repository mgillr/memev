### Added

- `memev cloud funnel on --yes` lets the tailscale tunnel go public through a Tailscale Funnel, for cloud AI apps, and `memev cloud funnel off` withdraws it. Without that consent the tunnel stays tailnet only, and choosing the provider (`memev cloud use tailscale`) never gives it.

### Fixed

- Memev no longer replaces a Tailscale serve or funnel that something else set up on https 443: it leaves it exactly as it is, does not turn it off when remote access stops, and `memev cloud status` says the port is in use.
