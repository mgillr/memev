### Added

- `docs/DOCKER.md` documents the Docker path end to end: the persistent `memev-vault` volume, the loopback-only port, the unprivileged user, the health check, every environment variable the image reads, the pull-and-run example (with a placeholder image name until a registry is decided), the upgrade path (`docker compose pull` and `up -d`) and safe shutdown (`down` keeps the volume).
- `scripts/docker-smoke.sh` runs the whole persistence check against whatever image `MEMEV_IMAGE` names, or a local build when it is not set: build or pull, start, wait for healthy with a deadline, check that an MCP call without a token through the published port is refused with 401, write a note unique to the run through the CLI inside the container, restart, read that note back, and check that `down` keeps the volume, found by its exact name. It runs in a compose project of its own (`memev-smoke`), so a memev deployed from the same checkout keeps its container and its volume, and it removes the `memev-smoke` volume at the end. It exits non-zero naming the failed step.

### Changed

- The daemon refuses to start on a vault config with a syntax error: it logs one line naming the file and exits non-zero without a stack trace, instead of silently starting on defaults. It refuses on every start, in the container or not, so `memev doctor`'s daemon check names the file as the reason the daemon is not running.
- The image keeps the config folder in the vault volume (`MEMEV_CONFIG_DIR=/vault/.memev/user-config`): the signing key, the licence, the trial record and the device key now survive a new container. The folder is inside `.memev/`, which the vault's git ignores. A container made from an earlier image kept them in the container, so install the licence again after the upgrade.
- `compose.yaml` takes the image name from `MEMEV_IMAGE` (default `memev:local`). The image sets `MEMEV_PORT=7787`; `compose.yaml` passes `MEMEV_PORT` to the container and publishes that port on loopback, and the health check probes it. The health check also gets `--retries=3` and `--start-period=10s`.
