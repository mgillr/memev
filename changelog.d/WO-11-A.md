### Added

- Regression guards for the four paid paths: the relay down with the vault working through the git backup, a same-note conflict keeping both versions byte for byte (the merge engine reached once when the licence allows it, never when it does not), an expired licence past its grace period, and changing the licence tier.
- A doctor check for each paid path, named on every run, with a row for each in the troubleshooting table: `relay`, `merge`, `license-expired` and `license-change`. The relay check says what the backup line says: a first connect is not a failure, a relay the daemon is not holding is on but not running, the git backup carries the notes when there is one, and with none yet the check says so and points at `memev github setup`. The licence-change check compares the computers using the vault with the licence's count and, after a downgrade, names the ones past it, which can read but not write until a licence for more computers is installed, with no re-enrolment. A file one of these checks cannot read is reported on that check instead of ending the doctor run.
