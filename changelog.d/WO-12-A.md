### Added

- The weekly funnel report adds a monthly verdict with `--month N`: each of the gates held in `scripts/metrics/gates.json` renders as a row with its threshold, its measured value, the month it falls due and pass, miss, not yet due or not measured, and a missed gate prints the branch text held for it in the file, word for word. A gate whose count file was not handed in reads not measured, never 0 and a miss, in the gates at the top of the page as in the verdict, since both read the same counts. Installs print as downloads, and under the installs gate the page prints the installed rows of the opt-in milestone report as a floor of confirmed installs. Paying users are the distinct paid licences issued; trials, marked true or 1, are not counted. A gate file with no monthly gates gets one line saying so instead of no verdict. The Business pilot gate is marked planned in the file, because no code records a completed pilot yet, and reads planned, not measured. A month that is not a whole number of months, 1 or more, is refused with an error instead of dropping the verdict.
