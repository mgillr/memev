### Added

- `memev runner on <seat> --max-runs-per-day N` turns on an opt-in background runner for a seat: while `memev runner watch <seat>` runs, every task the operator posts to the seat starts a headless turn of the seat's app, at most N runs a day. It is off by default and there is no default limit: the runner refuses to start without one. `memev runner status` shows what is on and how many runs each seat has had today; `memev runner off <seat>` stops it.
