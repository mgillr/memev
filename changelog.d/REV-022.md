### Added

- The backup sync now runs every 5 minutes instead of every 30, and the daemon runs one sync when it
  starts and one commit and push when it stops, so a note written just before the daemon shuts down
  is in the backup.
- `memev github setup` now says the vault is synced every 5 minutes.

### Fixed

- The daemon's background sync waits on the network off its event loop, with a timeout, so a slow or
  unreachable backup remote no longer stops `memev start` from seeing the daemon, nor stalls its
  answers. The sync at stop is bounded to 3 seconds; what does not fit is left to the next start and
  recorded in the sync status.
