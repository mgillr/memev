### Fixed

- Vault creation now falls back to git init plus a symbolic-ref when git is older than 2.28 and does not support -b, and stops with a clear message when git init fails outright instead of leaving a half built vault.
- When git init fails, init now runs git init first, before anything is written, and removes only the folder or .git directory that this call created, so a person's existing files are never deleted and no half built vault is left behind.
