Quickstart

You need Node 22 or newer and git. In a copy of the Memev repository, run the install command:

npm install -g . && memev init --no-connect

It creates your notes folder, starts Memev and runs a self-test. It does not connect any AI app: connect each one you choose with memev connect <client>, then run memev ready and open a new session in that app.

One person on one computer is free, for good. See Personal for what is included, the complaints analysis for what Memev does about the problems people report, and how Memev compares with hosted memory services.
