Quickstart

Memev is operating infrastructure for human and AI work. The local vault preserves project state and provenance; the coordination bus connects supported AI tools; contracts and the project lifecycle distinguish assigned, executed, verified and accepted work.

You need Node 22 or newer and git. This quickstart assumes you already have access to a copy of the repository. Invited Free Core testers should follow the Free Core Preview guide included in their private repository checkout, which covers isolation and data-safety instructions.

npm install -g . && memev init

The installer creates a local vault, starts Memev, connects detected AI apps and runs a self-test. When it finishes, run memev ready and open a new session in each connected app. The local core works without a network; optional remote connectors and GitHub backup require deliberate setup. If setup did not ask you to choose a lead, the first fresh AI session asks which connected AI should coordinate the others. Your answer is recorded once; you can change it later from the terminal.

One person on one computer is the free core. It is currently an invited preview, not a general public release. See Personal for the scope, the continuity and memory-quality analysis for one supporting capability, and how Memev compares with hosted context tools.
