How Memev compares

Part of the Memev documentation. Up: the README.

Memev is operating infrastructure for human and AI work. It connects people, agents and tools through shared project state, coordination, governed execution, contracts and evidence-based verification. The local vault is the durable state substrate. This page compares that model with hosted context services and distinguishes current Free Core capabilities from planned team and multi-computer services.

Install

In a copy of the Memev repository, run the install command:

npm install -g . && memev init

Then follow the quickstart.

The approach

Multi-computer editingNot part of the Free Core; paid convergence and federation remain separate planned capabilitiesDepends on the service

The local vault keeps records inspectable and portable. The ProjectStore and Coordinator maintain local project state and task lifecycle; contracts describe obligations; evidence supports verification; and the communications bus coordinates connected tools. GitHub backup is optional and remains under the operator's control. These are capabilities around work, not a claim that Memev replaces the AI tools or project systems people already use.
