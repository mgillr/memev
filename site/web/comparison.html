How Memev compares

Part of the Memev documentation. Up: the README.

Memev is a local-first memory and team channel for AI apps. This page states the facts about how Memev works and the open standards it builds on, so you can compare its approach with hosted alternatives on your own terms.

Install

In a copy of the Memev repository, run the install command:

npm install -g . && memev init

Then follow the quickstart.

The approach

QuestionMemevA typical hosted memory service
Where your notes liveA folder of plain Markdown on your own computerOn the vendor's servers
Who can read themYou, unless you choose to shareThe vendor, subject to its policy
BackupA private GitHub repository under your own accountThe vendor's storage
How apps receive contextThe Model Context Protocol, an open standardUsually a proprietary API
Team sharingOne channel between computers you own, with no server in the middleThrough the vendor's cloud
If you stop payingThe notes are plain files you keepAccess may end
Turning the cloud link offThe optional web link can be switched offOften not applicable

Memev keeps notes as plain Markdown, so they stay readable and portable with no special tool. It hands context to apps over the Model Context Protocol, the open standard that many editors and assistants already support. It backs up to a private GitHub repository under your own account.

Sources

  • Model Context Protocol, the open standard Memev uses to hand context to apps: https://modelcontextprotocol.io
  • GitHub private repositories, where Memev stores your backup under your own account: https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories
  • CommonMark, the plain-text Markdown format Memev writes your notes in: https://commonmark.org

The "typical hosted memory service" column describes the common cloud-hosted pattern rather than any single product. Check each product's own documentation for its current terms.
