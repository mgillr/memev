Free Core

For one person on one computer at a time. Memev is operating infrastructure for human and AI work: shared project state, coordination across connected tools, governed execution, contracts and evidence-based verification. The local vault is the durable state substrate, not the whole product. The complete local core is free and has no account or subscription requirement.

Availability: the Free Core is currently an invited preview, not a general public release. Testers should use the isolated setup in the preview guide.

What is included

  • Local project state and provenance: the vault, knowledge graph, claims and durable records
  • Hooks in Claude Code, Codex and Gemini CLI, session-start hooks in Cursor, instructions in the other apps
  • The quality check, review inbox, audit and memev why
  • Signed contracts with local checks
  • The comms bus: every AI app on your computer gets a seat, and you can coordinate them from one session
  • memev doctor
  • Several cloud AI apps side by side through the secure link, such as Claude and ChatGPT, next to your local coding tools over MCP (up to 5 connectors counted; nothing is refused)
  • Backup to your own private GitHub repository

Price

Free.

Limits

  • One computer at a time, with no licence and no network needed. Adding a second computer to the vault needs a licence.
  • Switching computers goes through your own GitHub backup: once the backup is set up on the old computer, a new computer can join it.
  • Git sync is single-writer backup, not a way to edit on two computers at once.
  • No user accounts: whoever has a token reaches what that token allows.
  • Recall is keyword search. Paraphrases with no shared words are missed; optional local embeddings are planned.

Personal with more computers

planned

Edit on two machines at once, with nothing to resolve. One person, up to 3 computers and 10 cloud AI connectors. The licence is for that person and cannot be passed on. The AI apps on all the computers share one memory and one comms bus, over the secure link, with a key for each computer.

The price is $12/month or $120/year. This is an early-supporter price: it stays the same for as long as your subscription runs.

Planned, and not part of the price: merging concurrent edits through the convergence engine, end-to-end encrypted sync between the computers, a hosted encrypted backup and a stable address for the secure link.
