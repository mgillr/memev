Trial

planned

The Business trial is planned. It is free, and there is no price shown here. There are two ways to take part.

Path one: self-serve Business trial

For teams that use hosted AI providers, or a mix of them. The cloud-hosted trial is free and self-serve: you start it yourself, with no card needed.

Path two: sales-assisted pilot

For organisations that run an internal model, an air-gapped install, or a compliance-led rollout. We work with you to set it up. The size of the pilot is set by order form, and the term starts at install. The install is done with the container image, and the trial licence for it is free. The paid setup done by the operator applies to this path only; the self-serve path is free.

What is free

  • The cloud-hosted trial is free and self-serve.
  • The trial licence for an on-prem or self-hosted install is free.
  • Installing it yourself with the container image is free.

Setup done by the operator is a paid service, quoted per the rate card. No amount is shown here.

Terms

  • 14 days, extendable once by 14 days.
  • No card needed.
  • Nothing is deleted when a trial ends.

The member and computer counts for the trial are in the docs, not on this page.
